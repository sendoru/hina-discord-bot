# 2부 Vol.1 《불꽃과 그림자》 — 한국 서버 설정 조사 및 lore 반영 기록 (2026-11-16)

연결 이슈: [#514](https://github.com/sendoru/hina-discord-bot/issues/514) · 첫 lore PR 기준 자료

> **근거 수준 주의:** 2026-11-10 한국 서버의 공개 범위는 넥슨 공식 공지로 확인했습니다. **세부 장면과 발언은 한국 서버 게임 클라이언트 원문을 직접 확보하지 못했고**, 한국어 2차 스토리 정리/비공식 전사를 이용해 조사한 내용입니다. 이 문서는 한국어 게임 대사를 직접 대조했다는 뜻이 아닙니다. 운영 반영 시에는 아래 *장면 검수 체크리스트*를 반드시 확인해 주세요.

## 범위 및 출처

- 대상: 메인 스토리 **제2부 Vol.1 《불꽃과 그림자》 1장 「게헨나를 다시 위대하게!」 1~17화, 2장 「우리는 불꽃이 되어」 1~21화**, 2026-11-10 한국 서버 공개.
- 같은 업데이트의 이벤트 《출항! 만마선 ~마코토 의장님의 화려한 피서~》는 **별도 이야기**이므로 이번 메인 스토리 corpus에 합치지 않습니다.
- 일본 서버 전용 후속 전개·유출·앞으로 나올 확정되지 않은 흑막은 반영하지 않습니다.

기록에서 사용하는 `confidence=crosschecked`는 **2차 자료를 대조·정리한 수준**이며, 한국어 게임 원문 직접 검증(`verified`)을 의미하지 않습니다. `kr_release=confirmed`도 해당 **장/에피소드의 한국 서버 공개 여부**이지 개별 대사에 대한 1차 검증을 뜻하지 않습니다. 새로운 항목은 무단 확정이나 세부 기계적 원리 상상을 피하기 위해 **사건의 최소 의미**로 작성합니다.

## 사건 흐름 (2차 자료에 기반한 검증 후보)

| 장·화 | 핵심 사건·서사적 위치 | 히나 시점의 지식 경계 |
| --- | --- | --- |
| 1장 1~6화 | 마유미·카렌·쇼코의 게헨나재흥위원회가 질서 강화를 추진; 히나와 직접 접촉해 선도부 측 불간섭을 얻는 장면 | 히나는 **직접 접촉**했지만 위원회의 숨은 계획을 이때부터 안 것은 아님 |
| 1장 12~15화 | 방송실 접근과 방송망 확장. 정비/연설 제안에 숨은 의도가 있는지는 당시 인물마다 정보 차이가 있음 | 히나가 직접 보지 못한 쇼코의 사적 행동·의도를 히나의 기억으로 넣지 않음 |
| 1장 16~17화 | 방송 뒤 히나·마코토 등 3학년을 중심으로 비정상적인 공격적 행동이 나타남. 이후 NK 울트라의 정신조작으로 설명됨 | 변화된 행동을 히나의 자발적 정치적 신념으로 처리하지 않음 |
| 2장 1화 | 사츠키가 과거 뇌제 체제와 정신조작 유산, 당시 반뇌제 세력에 관해 설명 | 히나는 설명 장면에 없는 것으로 정리되므로 **직접 인지 금지** |
| 2장 2~10화 | 영향받지 않은 후배들과 동료들이 저항을 조직하고 방해 방송을 준비 | 히나가 부재한 협의·증언을 자동으로 알지 않음 |
| 2장 11~18화 | 선생 구조·방송실 탈환; 조종당한 히나와 후배들의 대치; 정신조작 해제 과정과 쇼코의 정체 관련 전개 | 히나의 직접 행동과 사후 인식은 구분. 다른 인물의 독백은 관객 전용 |
| 2장 19화 | 히나가 책임 문제를 외면하지 않고 이오리·치나츠 등의 후배에게 사과. 마코토가 공식 책임 문제에 개입 | 세뇌 중 행동의 **원인**과 회복 후의 **책임 인식**을 분리 |
| 2장 20~21화 | 사건 후 관계 회복, 히나·선생의 성찰 장면. 보덴자츠/별도 배후에 대한 언급은 추측 또는 일부 인물에게만 전달 | 추측을 확정 흑막으로 만들지 않고, 히나가 들었다는 근거가 없으면 `audience_only` |

위 표는 **게임의 사건 순서**입니다. 2년 전으로 언급되는 뇌제의 통치·반뇌제 활동은 플래시백/과거 설명이지 2026년 출시 전후를 뜻하지 않습니다. 정확한 2년 전 표현과 3학년 집중 영향의 원인은 한국어 2장 1화 대사 검증 대상입니다.

## 기존 lore와 중복 방지

- `canon.abydos.hina_makoto.track_shemata`: **유지**. 이전 셰마타 관련 공동 추적은 이번 사건 이전부터 존재한 접점이지만 '마코토와 화해했다'는 뜻이 아닙니다.
- `canon.hina.unknown_shemata_before`: **유지**. 과거에 열차포의 존재를 몰랐던 시점과 이번 사건 이후의 지식을 혼동하지 않습니다.
- `canon.gehenna.makoto_vs_hina.pandemonium_institutional_conflict`: **유지**. 사건 당시 세뇌 상태의 동조나 회복 후 책임 문제는 평소 관계가 사라졌다는 근거가 아닙니다.
- `canon.serenade.hina_satsuki.hears_hypnosis_report`: **유지**. 소야곡 이벤트의 사츠키 최면과 뇌제 유산인 NK 울트라 정신조작은 별도 사건입니다.
- 신규: 재흥위원회의 직접 접점, 히나의 권력 행사 원칙, NK 울트라의 외부 영향과 후배 대치, 회복 후 사과·성찰 및 마코토와의 장면.
- 참고 전용(`audience_only`): 사츠키만 설명한 역사적 세부, 쇼코의 폭로, 일부 다른 인물의 배후 추측.

`audience_only`는 현재 `RAG_MODE=full`에서 인캐릭터 프롬프트에 포함되지 않습니다. 사용자 요청이 직접 질문이라고 해도 히나가 남몰래 들은 것으로 바꾸지 않습니다. *모델의 합리적인 문맥 추론 자체를 무조건 막는 신규 지침*도 추가하지 않습니다.

## 프롬프트 판단 (후속 PR)

- [`hina.md`](../../src/hina_bot/prompts/hina.md)는 이미 책임감, 힘의 절제, 공적 엄격함과 사적 태도 분리, 감정·관계의 상황별 변화 등을 충분히 다룹니다. 새 장면은 이를 **구체화**하는 증거이며 전면 개정 근거는 아닙니다.
- 1장 6화의 한국어 원문을 확인하고 기존 책임 섹션보다 명확한 원칙이 새롭게 드러났다면 **'권력을 가졌더라도 질서 자체를 위해 학생의 자유를 억누르지 않는다'는 취지의 한 문장**을 선택적으로 검토합니다.
- 세뇌 중 폭력성을 숨겨진 본성으로 간주하거나, 사건 직후 죄책감을 일상 대화의 상시 정서로 고정하지 않습니다.
- [`world_core.md`](../../src/hina_bot/prompts/integration/world_core.md)는 게헨나·만마전·선도부의 상시 기본 전제가 바뀌지 않았으므로 현재 **수정 불필요**로 판단합니다.

## 구현·검증

1. 인간 검토 가능한 짧은 summary + 정확한 장/화 locator와 출처 유형으로 `lore.jsonl`에 신규 항목을 추가합니다. 공식 한국어 장면 직접 확인 전에는 `verified`를 쓰지 않습니다.
2. `hina-lore validate`, corpus ID 유일성, full 모드의 `audience_only` 제외 및 인지 범위를 확인합니다.
3. `evals/character_lore_cases.jsonl`에 세계관 오인·인물 관계 과잉 일반화·DM 일상 감정 고정 방지 질문을 넣습니다.
4. PR 검토 단계에서 한국어 원문을 대조해 출처 수준을 높이거나 잘못된 요약을 수정합니다. 운영 배포 후에는 full lore 컴파일을 위해 재시작 및 비용 관측이 필요합니다.

이 문서와 이벤트 서사는 자동으로 런타임에 주입되지 않습니다. 봇에 실제로 주입되는 내용은 검수 후 `lore.jsonl`에 승인된 항목과 기존 프롬프트입니다.
